# 나의 사상체질 관련 특성 알아보기

평소 행동과 신체 상태를 돌아보는 **참고용** 한국어 웹 설문입니다.
체질을 확정하지 않고, 응답에서 확인된 행동·생활 특성을 영역별로 요약합니다.

- 유형 판별에는 KS-15 원본 문항(문항 2~15)과 논문 부록의 **성별·체질별 가중치표**를 사용합니다. 선택한 보기의 가중치를 체질별로 합산해 점수가 가장 높은 유형을 "가장 가까운 유형(참고용)"으로 보여줍니다.
- **공식 KS-15 결과와 다를 수 있습니다.** 공식 방식은 이 점수에 BMI를 더해 다항 로지스틱 회귀로 확률을 구하지만, 회귀 계수는 확인한 논문들에 실려 있지 않아 적용하지 않았습니다(BMI도 묻지 않습니다). 그래서 확률·정확도 수치는 만들지 않습니다.
- KS-15는 태음인·소음인·소양인만 판별하며 **태양인은 판별 대상이 아닙니다.** 연구에서 전문가 진단과의 일치율은 약 60% 안팎(일본인 50명 대상 60.0%)으로 보고되었습니다.
- 수면 2문항과 최근 변화 2문항은 점수 계산에 쓰지 않는 자체 문항입니다.
- 음식 제한, 약·한약 추천, 질병 예측은 제공하지 않으며, 의료적 진단을 대신하지 않습니다.
- 이름·전화번호·생년월일·사진·나이·키·몸무게는 수집하지 않고(성별만 질문), 응답은 서버로 전송하거나 저장하지 않고 브라우저 메모리에서만 처리합니다. 외부 AI API 없이 정적 HTML/CSS/JS로 동작합니다.

## 기능
- 한 화면 한 문항, 진행률, 이전/다음, 답변 수정 시 기존 응답 유지
- 18문항(성별에 따라 대변 신호/야간 소변 중 1문항만 표시), 모두 필수 응답 (미응답 시 부드러운 안내). 건너뛰기가 필요한 문항은 `js/data.js`에서 `skippable: true`를 주면 "잘 모르겠음 / 응답하지 않음"이 생깁니다
- 결과: 행동·대인관계 / 소화·식사 / 땀·온도 / 수면·생활 리듬 요약, 엇갈린 응답은 "상황에 따라 다르게 나타나는 편이에요"
- 미응답은 계산 제외, 응답 부족 시 판단 보류, 최근 변화 응답 시 안내 문구
- **결과를 PNG 이미지로 저장** (모바일은 공유 시트, PC는 다운로드)
- 어르신을 위한 큰 글씨 + 상단 글씨 크기 조절(기본/크게/아주 크게), 키보드(숫자키·←→) 지원

## 실행 방법
빌드가 필요 없습니다.

```bash
git clone https://github.com/kimmake/Sasang-constitution.git
cd Sasang-constitution
python3 -m http.server 8000   # 후 브라우저에서 http://localhost:8000
```
`index.html`을 더블클릭해서 열어도 동작합니다.

## 링크로 배포하기
**GitHub Pages (권장, 무료)**
1. 저장소 → Settings → Pages
2. Source: `Deploy from a branch`, Branch: `main` / `(root)` → Save
3. 1~2분 뒤 `https://kimmake.github.io/Sasang-constitution/` 로 접속, 이 링크를 공유

**Netlify / Vercel / Cloudflare Pages**: 저장소를 연결하고 빌드 명령 없이, 출력 폴더는 루트(`/`)로 지정합니다.

## 문항·결과 규칙 수정
모두 `js/data.js` 한 파일에 있습니다 (문항, 보기, KS-15 가중치표 `ks15.weights`, 결과 문장). 여성·소음·'여성적' 가중치는 논문에 `12`로만 인쇄되어 있어 그대로 썼으니, 오탈자라면 해당 값만 고치세요.
규칙을 적용하는 코드는 `js/result.js`, 화면은 `js/app.js`, 이미지 저장은 `js/image.js`입니다.

결과 생성 규칙 요약:
- 유형 점수 = 성별에 해당하는 KS-15 문항 응답의 가중치 합 (태음·소음·소양). 가장 높은 점수의 유형 표시, 동점이면 판단 보류
- 영역별 요약 문장은 선택한 보기를 그대로 문장으로 보여줌 (좋고 나쁨 등급 없음)
