# 나의 사상체질 관련 특성 알아보기

평소 행동과 신체 상태를 돌아보는 **참고용** 한국어 웹 설문입니다.
체질을 확정하지 않고, 응답에서 확인된 행동·생활 특성을 영역별로 요약합니다.

- 본 설문은 KS-15의 평가 영역을 참고하고 자체 보충 문항을 더한 것입니다. **검증된 KS-15 원본 검사가 아닙니다.**
- 체질별 점수·확률·판정, 음식 제한, 약·한약 추천, 질병 예측을 하지 않습니다.
- 이름·전화번호·생년월일·사진을 수집하지 않으며, 응답은 서버로 전송하거나 저장하지 않고 브라우저 메모리에서만 처리합니다(새로고침하면 사라집니다).
- 외부 AI API, 빌드 도구, 라이브러리가 없는 순수 HTML/CSS/JS 정적 사이트입니다.

## 기능
- 한 화면 한 문항, 진행률, 이전/다음, 답변 수정 시 기존 응답 유지
- 필수 문항 미응답 시 부드러운 안내, 민감 문항에 "잘 모르겠음 / 응답하지 않음"
- 결과: 행동·대인관계 / 소화·식사 / 땀·온도 / 수면·생활 리듬 요약, 엇갈린 응답은 "상황에 따라 다르게 나타나는 편이에요"
- 미응답은 계산 제외, 응답 부족 시 판단 보류, 최근 변화 응답 시 안내 문구
- **결과를 PNG 이미지로 저장** (모바일은 공유 시트, PC는 다운로드)
- 어르신을 위한 큰 글씨 + 상단 글씨 크기 조절(기본/크게/아주 크게), 키보드(숫자키·←→) 지원

## 실행 방법
빌드가 필요 없습니다.

```bash
git clone https://github.com/kimmake/Sasang-constitution.git
cd Sasang-constitution
python3 -m http.server 8000   # 후 브라우저에서 http://localhost:8000
```
`index.html`을 더블클릭해서 열어도 동작합니다.

## 링크로 배포하기
**GitHub Pages (권장, 무료)**
1. 저장소 → Settings → Pages
2. Source: `Deploy from a branch`, Branch: `main` / `(root)` → Save
3. 1~2분 뒤 `https://kimmake.github.io/Sasang-constitution/` 로 접속, 이 링크를 공유

**Netlify / Vercel / Cloudflare Pages**: 저장소를 연결하고 빌드 명령 없이, 출력 폴더는 루트(`/`)로 지정합니다.

## 문항·결과 규칙 수정
모두 `js/data.js` 한 파일에 있습니다 (문항, 보기, 영역, 결과 문장, 임계값).
규칙을 적용하는 코드는 `js/result.js`, 화면은 `js/app.js`, 이미지 저장은 `js/image.js`입니다.

결과 생성 규칙 요약:
- 응답을 0~1로 환산하고 미응답·"잘 모르겠음"은 제외
- 한쪽 응답은 "그런 편" 이상, 다른 쪽은 "그렇지 않은 편" 이하이면 `엇갈림`
- 그 외 평균이 0.7 이상 / 0.3 이하 / 그 사이로 문장 선택
- 영역 내 응답이 60% 미만이면 해당 영역, 전체 본 문항 응답이 60% 미만이면 전체 판단 보류
